# breast-cancer-diagnostic-analysis
Exploratory analysis and classification modeling using the Wisconsin Breast Cancer Diagnostic dataset

The dataset included 569 observations. Benign cases were more common than malignant cases, with 357 benign cases and 212 malignant cases. In the exploratory summary, malignant cases had higher average radius, texture, perimeter, area, and smoothness compared with benign cases. The boxplot for mean radius also showed a clear upward shift in malignant cases, suggesting that tumor size-related features may help distinguish malignant from benign diagnoses.
